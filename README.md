# DOFFA Heroes

The first flagship game in the DOFFA Games universe.

This repository starts clean. It does not contain or depend on the retired DOFFA token, lost reward wallet, private keys, seed phrases, or production mint addresses.

## Status

Pre-production and vertical-slice development.

The initial milestone is a playable, original action-roguelite prototype inspired by the room-based progression loop of Archero, with original DOFFA mechanics, code, art direction, characters, enemies, levels, UI, audio, and economy.

Token integration will begin only after the core game is playable, server-authoritative reward validation exists, and the reward economy has been tested without real assets.
