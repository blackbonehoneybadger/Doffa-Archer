# DOFA Archer — действующее направление

Последние указания пользователя имеют приоритет над прежним true-3D production-контрактом.

- Фиксированная верхняя камера, портретная арена, движение и автоматическая атака при остановке. Допускается 2.5D.
- Собственные визуал, герои, интерфейсы и анимации. Archero — ориентир игрового ритма.
- Демо: 5 туров по 50 комнат. Боссы в 10/20/30/40; Капризарт в 50. Его лицо запрашивается до создания персонажа.
- Кофейная тематика объектов и существ: выращивание, обработка, обжарка, помол, давление, экстракция. Переименование старого окружения не считается готовой переработкой.
- Honey Badger — сухой атлетичный ниндзя, STRONG ROOTS. Пата — стройнее, лицо и аксессуары сохранить. Остальные утверждённые лица не менять.
- До 1000 собранных зёрен в сутки. Выигрыши не входят в лимит сбора. Ставка списывается при входе; победа во всех 50 комнатах возвращает 2× ставки, поражение — 0.
- Будущая полностью просмотренная реклама даёт ещё 2× выплаты, однократно и после проверки провайдером. Сейчас рекламный провайдер не подключён.
- Будущий курс: 1000 зёрен = 1 DOFO. Сейчас токен не подключён.

## Текущие ограничения

Локальные зёрна демонстрационные; localStorage не является защищённым балансом. Реальные выплаты требуют серверного журнала, проверки забега и подтверждения рекламы. Код браузера доступен клиенту.

Единый веб-артефакт: `npm run build` → `dist`. `npm start` строит и запускает его; Vercel использует тот же build/output. APK ещё не собран. Старые технические идентификаторы сохранены для совместимости сохранений.

## Уточнение: герои и мир

Кофе обрело разум, захватило мистера T и превратило его в Капризарта. Пять героев противостоят его порождениям. В конце каждого тура — новое воплощение с тем же лицом, другим телом и оснащением; уничтожается воплощение, а не сам антагонист.

Движение справа; слева две компактные кнопки выбора ближней/дальней атаки.

| Герой | Ближняя | Дальняя |
|---|---|---|
| Honey Badger | Катана | Сюрикены |
| Mr. Kroo | Кинжал | Лук |
| Boy | Молот | Золотой Desert Eagle |
| Пата | Кастет без крестов | Ружьё |
| Хадида | Бита | Тлеющие докуренные бычки, бросок пальцами |

Каждому оружию необходимы собственные изображение и анимация. У каждой темы тура — отдельные враги и 50 отличающихся комнат. Не считать уникальный ID доказательством визуальной уникальности. Сложность растёт между турами, сохраняя возможность пройти игру. Новые темы и комнаты создаются самостоятельно; референсы обязательны для идентичности персонажей.
